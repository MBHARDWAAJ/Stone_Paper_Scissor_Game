✂️ Stone Paper Scissors Game 🪨📄
A fun and interactive Stone Paper Scissors game built using Python, where you play against the computer!

📌 About The Project
This is a simple command-line based Stone Paper Scissors game where the player competes against the computer. 
The computer makes a random choice every round, and the game determines the winner based on the classic rules.

🎮 How To Play
Run the Python script
Enter your choice: Stone, Paper, or Scissors
The computer randomly selects its choice
The winner is announced based on the rules:
🪨 Stone beats ✂️ Scissors
📄 Paper beats 🪨 Stone
✂️ Scissors beats 📄 Paper
Play again as many times as you want!
